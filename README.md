# 🏥 Elite Care Hospital — Responsive Medical Website

A modern, responsive, 10-page hospital website designed for **Elite Care Hospital**. Built using pure **HTML5**, **CSS3**, and **Vanilla JavaScript** with a self-contained single-file architecture per page (embedded CSS & JS), featuring a refined **Navy Blue, White, and Champagne Gold** medical design system and continuous lightweight medical animations.

---

## ✨ Key Features

- **10 Complete Interfaces:** Covers every essential hospital department and patient service.
- **Refined Color Palette:** Navy Blue (`#0A1E3D`) & White (`#FFFFFF`) as primary colors with subtle Champagne Gold (`#C5A059`) luxury accents.
- **Continuous Medical Animations:** Live SVG ECG heartbeat wave (`ecgDraw`), pulsing emergency vital indicator (`vitalRing`), gentle heartbeat icons (`heartBeat`), and smooth floating cards.
- **Fully Responsive Design:** Adapts seamlessly across desktop, tablet, and mobile screens with a collapsible hamburger navigation menu.
- **Interactive Vanilla JS Components:**
  - Specialty filtering on the **Doctors** page (`Cardiology`, `Neurology`, `Orthopedics`, `Pediatrics`).
  - Interactive FAQ accordion on the **FAQ** page.
  - Inline booking and contact form confirmations without page reloads.
- **Self-Contained Pages:** Each `.html` file includes its own internal `<style>` and `<script>` blocks—no build tools or external CSS/JS folders required.

## 📄 Pages Overview

| File Name | Page Title | Description |

| `index.html` | **Home** | Hero with live ECG animation, quick highlights, hospital gallery, campus showcase, and featured departments. |

| `emergency.html` | **Emergency 24/7** | 24/7 Emergency & Trauma Care details, 3-minute triage info, and direct hotline callout. |
| `blog.html` | **Health Blog** | Featured preventive medicine guide and physician-reviewed wellness articles. |
| `faq.html` | **FAQ** | Interactive accordion covering clinic hours, insurance, visiting hours, and digital lab reports. |
| `contact.html` | **Contact Us** | Campus address, emergency & reception numbers, email support, and interactive contact form. |
